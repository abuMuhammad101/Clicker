# S-8 references (Mobbin)

One search was run (the time box for research was spent on building, and the screens the search returns cost a lot of context): "Mercury banking app sign in screen", web. Mobbin returned three Mercury screens, none of them its sign-in: the home screen twice and the transactions list. Nothing below is claimed about a sign-in screen I did not see.

What the Mercury screens gave, and what was taken:

- **A welcome that is one calm line** ("Welcome, Sam"), then a row of the few actions that matter, then quiet cards. Taken: the home greeting stays the only serif line, the welcome note under it is one sentence, and "Waiting for you" is a row of quiet cards, not a dashboard. ([Mercury home](https://mobbin.com/screens/d575358b-679b-4d52-aa98-5026970291b3))
- **Counts as plain numbers**, a task count beside the sidebar item ("Tasks 1"), nothing red or pulsing. Taken: the card's count is a number in the interface font with tabular figures; no urgency styling, hidden at zero. ([Mercury home](https://mobbin.com/screens/a0539f69-cca9-4645-8f3d-aa59048efdd1))
- **A list with figures above it** ("Net change this month", "Money in", "Money out") that read before the table does: already how Clicker's summary strip works; no change.

Not taken: anything promotional on the sign-in screen. The screen keeps its existing centred card (wordmark, organisation name, one line of promise from the organisation setting) because the form is two fields and a split layout would only add a picture.
